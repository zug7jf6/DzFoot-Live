# DzFoot Live ⚽

A responsive Arabic football hub for La Liga and Algeria's Ligue 1.

- No account or login required.
- Responsive animated landing page.
- Links to official fixtures, results and standings sources.
- Only points visitors to official/legal viewing options when available; it does not host streams.

## Deploy on Render

Create a **Static Site** connected to this repository:
- Branch: `main`
- Build command: leave blank
- Publish directory: `.`
- Auto-deploy: enabled

The website is a single static `index.html` file and does not require secrets or a backend.
